## 📊 Data in the Wild

Three projects. Real problems. Real solutions.

### 🏥 Healthcare Access Deserts in East Africa
> Merged four real-world datasets to map communities across Kenya, Ethiopia, Tanzania, Uganda, and Rwanda living more than 10km from the nearest clinic. Built a vulnerability score for every district and deployed it as a live interactive map.

### 💸 Mobile Money Fraud Detection
> Built a machine learning model detecting fraudulent mobile money transactions. Handled class imbalance with SMOTE, comparing Logistic Regression, Random Forest, and XGBoost.

### 📉 Kenya Economic Inequality Analysis
> Used SQL and R to analyse economic inequality across Kenya's 47 counties. Queried a SQLite database, ran multiple regression models, and visualised which counties are being left behind — and why.
